### Part A. Anti-slop rules

Each rule says what is forbidden and how it is checked. A rule with a command is checked by pasting the command and its complete output into `$R/slop-audit.md` (A-S). The reviewer rejects on any failure (A-R).

**A1. Evidence and numbers.**
1. Every number in a record, `docs/STATUS.md`, `docs/benchmarks/`, a commit message or a hand-back note comes from a command you ran, and the text names the command and the log holding its complete output. A number no log contains is fabricated.
2. Logs are complete: `> "$LOG" 2>&1`, grep afterwards. Never pipe a test, gate or benchmark through `head`, `tail`, `cut` or `grep` before saving (2026-09-29: a `| tail -40` kept one of ~14 Rust test binaries' results). Exit code from the command, not the pipe.
3. Summaries computed from the saved log, command shown: Go `rg -c '^ok\s' "$LOG"` and `rg -n '^(--- FAIL|FAIL\s|panic:)' "$LOG"` (nothing); Rust `rg -n '^test result:' "$LOG"` (all `ok.`, `0 failed`) and `rg -n 'FAILED|panicked' "$LOG"` (nothing); box gate `rg -n '^(clippy_warnings|rss_lines|remote_exit)=' "$LOG"` showing the merge-base clippy count (≤6, measured on `MB` and cited), `rss_lines=ok`, `remote_exit=0`.
4. A skipped test is not a pass. `TestCodexHooksEndToEnd` and `TestCodexHooksTrustAgainstTheInstalledCodex` skip without `XMUSTARD_CODEX_BIN` (and `node`) (`api-go/cmd/xmustard-api/hooks_codex_test.go:272-278`, `api-go/cmd/xmustard-ops/codex_hooks_test.go:274-276`). A cited test needs a `-v` log with `--- PASS: <name>` and a pasted `rg -n -- '--- SKIP' "$LOG"`.
5. Load and platform with every timing and memory number: Mac or box, `uptime` load average, release or debug binary.
6. Spot check: the reviewer picks five numbers from the record and runs `rg -F '<raw logged string>' <log>` for each (S13 lists the raw string beside any converted figure). One miss rejects the record.

**A2. Completion claims.** "Done", "merged", "passes", "fixed", "verified" appear only next to the output showing it (`remote_exit=0` with log path, `gate=PASS`, the merge sha). Status words: done, partial, not done, blocked (reason), parked, not run (reason). A deviation from the row is a numbered deviation with a reason, never folded into "what was built".

**A3. No stubs counted as done.** No `TODO`, `FIXME`, `XXX`, `HACK`, `unimplemented!`, `todo!()`, `panic("not implemented")`, placeholder returns or "for now" paths in a diff that claims a deliverable; no function returning a constant where computation is asked, no handler returning 200 with an empty body, no flag that parses and does nothing. A `TODO` that must stay names a `WS-NN` owner and has a `FU` line; the deliverable is then partial. Check: S1.

**A4. Tests.**
1. Every new test asserts what its name claims and fails when it breaks. The author proves it with one mutation per new test (or per table): change one implementation line, run the focused test, paste the `FAIL` line, restore with `git checkout -- <file>` **only on a tree `git status --short` showed clean before the mutation**, paste the clean status after. A test that survives its mutation is a finding. The reviewer reruns two sampled mutations and pastes their `FAIL` lines into `triage.json`'s `evidence`.
2. No test mirrors the implementation: expected values are literals or come from an independent oracle (recorded fixture, golden generated on the unchanged base, reference implementation).
3. No test that asserts nothing ("did not panic", `err == nil` unless the name says so; `t.Log` in place of `t.Error`; assertions inside a branch the fixture never takes).
4. Security guards are tested on the refusal path.
5. Goldens regenerate only with the documented variable, and the record says which goldens changed and why each change is intended. Regenerating a golden to make a failing test pass without that sentence is a blocker.
6. Load-sensitive assertions follow WS-FIX-06; no raised timeout or added retry without a measured reason.
7. Check: S5 (gate-enforced: each S5 test needs a mutation row).

**A5. Comments.** No comment narrating the code or its editing history ("Now we", "First,", "Step 3", "This function", "Added", "Changed", "Updated", "Fixed", "New:", "as requested", "per review"). Doc comments on exported identifiers and non-obvious invariants are house style and stay. Check: S2, S3.

**A6. No duplicate helpers.** Before adding a function, type or package: xMustard `search` (B6) and `rg -n 'func (\([^)]*\) )?<Name>\b' api-go` (or the Rust/TS equivalent), both pasted in `dogfood.md`. Existing helpers: `internal/gitdiff` (diff arguments, scrubbed git env), `safepath`/`ConfineWorkspacePath`, `transport.ValidWorkspaceID`, `evidence.CapBytes`, `internal/anchor`, `internal/review`, the shaper registry in `internal/evidence`, MCP resources in `docs_resource.go`/`evidence.go`. A second copy is a major. No single-implementation interface, no two-or-three-case table, no renaming wrapper. Check: S6.

**A7. No dead flags or speculative config.** Every new CLI flag, env variable, config key or JSON field is (a) read on a non-test path, (b) exercised by a test, (c) documented where users look (`README.md`, `docs/SECURITY.md`, the MCP docs resource, or the ops `usage:` string), (d) named in the row or justified in the record. New env variables also carry the WS-48 note. Check: S7.

**A8. Docs match shipped code.** A doc line describes what `feat/parity-v2` does at the commit adding it; planned behaviour is written as planned with its `WS-NN`, or not at all. Every changed behaviour sentence maps to a test or command in the record's *checks*. README stays free of workstream jargon; "not a parity claim" stays. Check: S8.

**A9. Scope.** The diff touches the row's Files list, its tests and fixtures, the plan record; every other file gets one line in the record (path, why). No drive-by reformatting, no renames outside the row, no dependency bumps inside a feature commit. Check: S9.

**A10. Idiom and style.** Match the surrounding code (`%w` wrapping where callers use `errors.Is/As`, table-driven tests where the package uses them, existing route/gate/dispatch tables). Patterns over branching (§4 rule 10); guard clauses stay. `gofmt` clean on changed Go files; `cargo fmt --check` adds no newly flagged file beyond H8's three. Check: S4, S12.

**A11. Small, reviewable commits.** Each commit compiles, passes its focused tests, and does one thing (dependency, behaviour-free refactor proven by goldens, feature, fix per round, record). A commit adding more than 800 non-test, non-fixture, non-doc lines says in its body why it could not be split; a workstream above 2,500 such lines is split into lettered sub-workstreams before review (WS-28's feature commit: 1,152). Review fixes are new commits, never amends. Check: S10.

**A12. Honest reporting.** Hand-back, record and `FU` list what is not done, not run and still open, as prominently as what is done. A result contradicting an earlier claim is reported as a correction with evidence. A failed or unavailable tool is stated with its substitute; never paper over a missing channel.

**A13. Safety rails.**
1. Never point a branch binary at `/Users/for_work/.xmustard-eval/data` (schema 4 / CSR 2 break v0.1.1); branch binaries use `/Users/for_work/.xm-parity-scratch/data` and scratch ports; never replace anything under `~/.xmustard-eval/bin`.
2. No box identifier anywhere committed or quoted (§4 rule 2). S11 reads `LP` and prints counts only; run it on `git diff --cached` before every commit as well.
3. Never edit the integration tree outside §3 step 6, and never while the lock exists (unless you hold it).
4. Real client configs and repositories: §4 rule 5.

**A14. Word and idiom greps** (S14): banned prose words in added `.md` lines; `\.unwrap\(\)` in added non-test `.rs` lines; `context\.Background\(\)` in added non-test `.go` lines under `cmd/xmustard-api`, `internal/mcpserver`, `internal/workspaceops`; emoji or `!` at sentence end in added prose. Each hit removed or explained.

```bash

LP=/Users/for_work/Developer/xMustard/.git/xm-parity/leak-patterns.txt

added() { git diff -U0 "$MB"..HEAD "$@" | rg '^\+' | rg -v '^\+\+\+'; }
section() { printf '\n## %s\n$ %s\n' "$1" "$2"; }
{

  echo "rg_exit=$? (1 = none)"

  section S3 'comment density (added comment lines / added non-blank lines)'
  echo "$(added "${CODE[@]}" | rg -c '^\+\s*(//|/\*|\* )') / $(added "${CODE[@]}" | rg -cv '^\+\s*$')"

  section S4 'formatting: gofmt on changed Go files, cargo fmt flagged files'
  git diff --name-only --diff-filter=AM -z "$MB"..HEAD -- '*.go' | xargs -0 gofmt -l
  echo "gofmt_listed_above (none = clean)"
  (cd rust-core && cargo fmt --check -- -l 2>/dev/null) | sort -u
  echo "changed .rs files:"; git diff --name-only --diff-filter=AM "$MB"..HEAD -- '*.rs'

  section S5 'new tests (each needs a mutation row below)'
  git diff -U0 "$MB"..HEAD -- '*_test.go' | rg -o '^\+func (Test\w+)' -r '$1'
  git diff -U0 "$MB"..HEAD -- '*.rs' | rg -A2 '^\+\s*#\[test\]' | rg -o 'fn (\w+)' -r '$1'
  git diff -U0 "$MB"..HEAD -- 'integrations/**/*.ts' | rg -o "^\+\s*(test|it)\(['\"]([^'\"]+)" -r '$2'

  section S6 'new Go functions whose name is defined more than once'
  added -- '*.go' | rg -o '^\+func (\([^)]*\) )?([A-Za-z0-9_]+)' -r '$2' | sort -u | while read -r n; do
    c=$(rg -c --no-filename "^func (\([^)]*\) )?$n\(" api-go | paste -sd+ - | bc)
    [ "${c:-0}" -gt 1 ] && echo "DUP? $n x$c"
  done
  echo "done"

  section S7 'new flags and environment variables'
  added -- '*.go' | rg -o 'fs\.(?:String|Bool|Int|Int64|Uint|Duration)\("([a-z0-9-]+)"|fs\.Var\([^,]+,\s*"([a-z0-9-]+)"' -r '$1$2' | sort -u
  added | rg -o 'XMUSTARD_[A-Z0-9_]+' | sort -u | while read -r v; do
    printf '%s existing_at_base=%s readers=%s\n' "$v" "$(git grep -q "$v" "$MB" -- api-go rust-core integrations && echo yes || echo no)" \
      "$(rg -l --glob '!*_test.go' "$v" api-go rust-core integrations 2>/dev/null | paste -sd, -)"
  done

  section S8 'added doc lines (map each behaviour claim to a test in the record)'
  added -- '*.md' ':(exclude)docs/plans'

  section S9 'changed files not named in the plan row'
  awk -v h="### $WSU " 'index($0,h)==1{p=1;print;next} p&&/^### /{exit} p' docs/plans/2026-09-25-parity-build-plan.md \
    | rg -o '`([^`]+)`' -r '$1' | sort -u > "$R/.planned.txt"
  git diff --name-only "$MB"..HEAD | grep -vxFf "$R/.planned.txt"
  rm -f "$R/.planned.txt"

  section S10 'per-commit size, non-test non-fixture non-doc'
  git log --no-merges --format='%h %s' --shortstat "$MB"..HEAD "${NONTEST[@]}"

  section S11 'leak patterns in added lines (counts only; the strings are never printed)'
  added | rg -n 'BEGIN (RSA|OPENSSH|EC) PRIVATE|xox[bp]-|ghp_[A-Za-z0-9]{20}|sk-[A-Za-z0-9]{20}'
  echo "rg_exit=$? (1 = none)"
  [ -s "$LP" ] || echo "box_leak_check=NOT RUN (pattern file missing: ask the owner)"
  git diff "$MB"..HEAD | rg -c -F -f "$LP"
  echo "box_leak_rg_exit=$? (1 = none)"

  section S14 'banned words, unwrap, context.Background, emoji'
  added -- '*.md' | rg -n -i '\b(enhanced|robust|comprehensive|seamless|leverage|utilize|ensure)\b|[\x{1F300}-\x{1FAFF}]|![ ]*$'
  echo "words_rg_exit=$? (1 = none)"
  git diff -U0 "$MB"..HEAD -- 'rust-core/src/**' ':(exclude,glob)**/tests/**' | rg -n '^\+.*\.unwrap\(\)' | rg -v '#\[cfg\(test\)\]|mod tests'
  echo "unwrap_rg_exit=$? (1 = none)"
  git diff -U0 "$MB"..HEAD -- 'api-go/cmd/xmustard-api/*.go' 'api-go/internal/mcpserver/*.go' 'api-go/internal/workspaceops/*.go' ':(exclude,glob)**/*_test.go' | rg -n '^\+.*context\.Background\(\)'
  echo "background_rg_exit=$? (1 = none)"
} > "$R/slop-audit.md" 2>&1
echo "wrote $R/slop-audit.md"
```

`source_refs` names each channel finding by `<channel>:<index>` (1-based order in that channel's `findings` array; `codex-review:<n>` is the n-th `[Px]` line of `codex-review.md`; `ocr-delegate:<n>`, `ocr-review:<n>` likewise). **Every channel finding must appear in some entry's `source_refs`**; the gate fails otherwise. Rules: (1) deduplicate same-path overlapping findings into one entry listing every ref, higher severity wins; (2) severity map: `critical`, `[P0]`, any security or trust bypass, data loss, a broken budget line, a failing gate, fabricated evidence → **blocker**; `high`, `[P1]`, or `medium`/`[P2]` describing wrong behaviour, an unmet spec requirement or a Part A reject criterion → **major**; the rest → **minor**; the reviewer may raise with a reason, lower only with evidence; (3) unanchored findings are read, never dropped: re-anchor or reject with `evidence: "unanchored: quote not in <MB>..<HD>; checked <file>:<line>"`; (4) closing: `fixed` needs `fix_commit` (a commit **after** the reviewed `HD`, contained in the branch) and `evidence` naming the test or command that shows the behaviour (for a bug, the regression test that fails without the fix); `rejected` needs `evidence` citing code or a test, and for a blocker/major `second_reviewer` equal to `reviewer.txt`'s reviewer (never the author); `deferred` is minors only, with the id in `FU` under the Sunday section; (5) open blockers/majors carry into round N+1 by id; the final ledger is copied to `.git/xm-parity/findings/ws<id>-findings.json` (the canonical findings shape from now on; `ws35-findings.json` is the closest older example). Optional: `review record` into the scratch store (`--producer agent`); `review triage` needs a verifier token and was not run.

"""Merge gate for one workstream review round (v2, 2026-09-30).

usage: xm-review-gate.py <review-dir> <worktree> <base-sha> <author> [followups.md] [--leak-patterns FILE]

def git(wt, *args):

    return hashlib.sha256(p.read_bytes()).hexdigest()


def kv(text):
    return dict(line.split("=", 1) for line in text.splitlines() if "=" in line)


def findings_of(r, name):

        return []
    doc = json.loads(p.read_text())
    return doc.get("findings", []) if isinstance(doc, dict) else []


def main():
    args = [a for a in sys.argv[1:] if not a.startswith("--")]
    leak_file = None
    if "--leak-patterns" in sys.argv:
        leak_file = sys.argv[sys.argv.index("--leak-patterns") + 1]
        args = [a for a in args if a != leak_file]
    rdir, wt, base, author = args[:4]
    followups = pathlib.Path(args[4]).read_text() if len(args) > 4 else ""
    r = pathlib.Path(rdir)
    errors = []

    # 1. files, seals
    for name in REQUIRED:
        if not (r / name).is_file() or (r / name).stat().st_size == 0:
            errors.append(f"missing or empty {name}")
    if not ((r / "ocr-review.json").is_file() or (r / "ocr-delegate.findings.json").is_file()):
        errors.append("missing ocr-review.json or ocr-delegate.findings.json")
    rng = kv((r / "range.txt").read_text()) if (r / "range.txt").is_file() else {}
    for name in SEALED + [n for n in OPTIONAL_SEALED if (r / n).is_file()]:
        want = rng.get(f"sha256 {name}")
        if not want:
            errors.append(f"range.txt has no sha256 for {name} (run xm-review-run.sh v2)")
        elif (r / name).is_file() and sha256(r / name) != want:
            errors.append(f"{name} changed after the run (sha256 mismatch)")

    # 2. spec present
    if (r / "background.md").is_file() and len((r / "background.md").read_text().strip()) < 40:
        errors.append("background.md is empty: the plan has no section for this workstream; add the spec-only commit first")

    # 3. reviewer identity
    rev = kv((r / "reviewer.txt").read_text()).get("reviewer", "").strip() if (r / "reviewer.txt").is_file() else ""
    if not rev:
        errors.append("reviewer.txt has no reviewer= line")
    elif rev in (author, rng.get("author", "").strip()):
        errors.append(f"reviewer {rev!r} equals the author")

    # 4. coverage on the reviewed range
    mb, hd = rng.get("merge_base", base).strip(), rng.get("head", "").strip()
    if not hd:
        errors.append("range.txt has no head=")
    changed = set(git(wt, "diff", "--name-only", mb, hd or "HEAD").stdout.split())
    diff_text = (r / "diff.patch").read_text(errors="replace") if (r / "diff.patch").is_file() else ""
    covered = set()
    for name in COVERAGE:
        p = r / name
        if not p.is_file():
            continue
        doc = json.loads(p.read_text())
        for c in doc.get("coverage", []):
            if c.get("status") != "reviewed":
                continue
            if name == "ocr-delegate.findings.json":
                q = (c.get("quote") or "").strip()
                if not q or q not in diff_text:
                    errors.append(f"delegate coverage for {c.get('path')} has no verbatim quote from diff.patch")
                    continue
            covered.add(c["path"])
    errors += [f"not reviewed by any channel: {p}" for p in sorted(changed - covered)]

    # 5. every channel finding is triaged
    triage = json.loads((r / "triage.json").read_text()) if (r / "triage.json").is_file() else []
    refs = set()
    for f in triage:
        refs |= set(f.get("source_refs", []))
    expected = set()
    for name in COVERAGE:
        chan = name.split(".")[0]
        for i, _ in enumerate(findings_of(r, name), 1):
            expected.add(f"{chan}:{i}")
    if (r / "codex-review.md").is_file():
        n = len(re.findall(r"\[P[0-3]\]", (r / "codex-review.md").read_text(errors="replace")))
        expected |= {f"codex-review:{i}" for i in range(1, n + 1)}
    errors += [f"channel finding {ref} is not referenced by any triage entry (source_refs)" for ref in sorted(expected - refs)]

    # 6. closure
    for f in triage:
        fid, sev, status = f.get("id", "?"), f.get("severity"), f.get("status")
        ev = (f.get("evidence") or "").strip()
        fix = f.get("fix_commit") or ""

        def fixed_ok():
            if not (ev and fix and hd):
                return False
            same = git(wt, "rev-parse", fix).stdout.strip() == git(wt, "rev-parse", hd).stdout.strip()
            after_head = git(wt, "merge-base", "--is-ancestor", hd, fix).returncode == 0
            in_branch = git(wt, "merge-base", "--is-ancestor", fix, "HEAD").returncode == 0
            return after_head and in_branch and not same

        closes = {
            "fixed": (fixed_ok, "fixed needs evidence and a fix_commit that is a strict descendant of the reviewed head and contained in HEAD"),
            "rejected": (lambda: bool(ev) and (sev not in GATED or (f.get("second_reviewer") == rev and rev != author)),
                         "rejected needs evidence, and for a blocker/major second_reviewer must equal reviewer.txt's reviewer"),
            "deferred": (lambda: sev not in GATED and fid in followups,
                         "only minors may be deferred, and the id must appear in the followups file"),
        }
        ok, why = closes.get(status, (lambda: False, f"status {status!r} does not close a finding"))
        if sev not in GATED | {"minor"}:
            errors.append(f"{fid}: severity {sev!r} is not blocker, major or minor")
        elif not f.get("source_refs"):
            errors.append(f"{fid}: no source_refs (which channel finding is this?)")
        elif not ok():
            errors.append(f"{fid} ({sev}): {why}")

    # 7. slop audit
    audit = (r / "slop-audit.md").read_text(errors="replace") if (r / "slop-audit.md").is_file() else ""
    for i in range(1, 14):
        if not re.search(rf"^## S{i}\b", audit, re.M):
            errors.append(f"slop-audit.md lacks heading S{i}")
    for s in ("S1", "S2", "S11"):
        sec = re.search(rf"^## {s}\b.*?(?=^## S\d|\Z)", audit, re.M | re.S)
        if sec and "rg_exit=1" not in sec.group(0):
            errors.append(f"slop-audit.md {s} does not report rg_exit=1")
    added = [l for l in git(wt, "diff", "-U0", mb, hd or "HEAD").stdout.splitlines() if l.startswith("+") and not l.startswith("+++")]
    if any(re.search(S1, l) for l in added):
        errors.append("gate rerun of S1 found a stub/TODO marker in the reviewed range")
    code_added = [l for l in git(wt, "diff", "-U0", mb, hd or "HEAD", "--", "*.go", "*.rs", "*.ts").stdout.splitlines() if l.startswith("+") and not l.startswith("+++")]
    if any(re.search(S2, l, re.I) for l in code_added):
        errors.append("gate rerun of S2 found a narrating comment in the reviewed range")
    if leak_file:
        pats = [p for p in pathlib.Path(leak_file).read_text().splitlines() if p.strip()]
        hits = sum(1 for l in added for p in pats if p in l)
        if hits:
            errors.append(f"gate rerun of S11 found {hits} box-identifier hit(s) in the reviewed range")
    s5 = re.search(r"^## S5\b.*?(?=^## S\d|\Z)", audit, re.M | re.S)
    if s5:
        tests = [t for t in re.findall(r"^(?:Test\w+|[a-z_][a-z0-9_]+)$", s5.group(0), re.M) if t not in ("done",)]
        for t in tests:
            if not any(t in l and "FAIL" in l for l in audit.splitlines() if not l.startswith("$")):
                errors.append(f"new test {t} has no mutation row (a line naming it with its FAIL output)")

    # 8. dogfood
    if (r / "dogfood.md").is_file():
        rows = [l for l in (r / "dogfood.md").read_text().splitlines() if l.startswith("|") and not re.match(r"^\|\s*-", l)]
        if len(rows) < 4:  # header + 3
            errors.append("dogfood.md has fewer than three table rows")

    for e in errors:
        print("GATE FAIL:", e)
    print(f"gate={'PASS' if not errors else 'FAIL'} changed={len(changed)} covered={len(changed & covered)} "
          f"channel_findings={len(expected)} triaged={len(triage)} reviewer={rev or '-'}")
    sys.exit(1 if errors else 0)


if __name__ == "__main__":
    main()
